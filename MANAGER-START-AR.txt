التحديث الحالي: STORE-MANAGER مستقل، وجميع بيانات إدارته داخل MongoDB.
ابدأ بدليل MANAGER-AR.md (في WWC داخل docs).

NSS: احتفظ بملف .env الحالي، وأضف WWC_MANAGER_USERNAME بيوزر المدير دون @، ثم شغّل python bot.py.
WWC: احتفظ بملف .env الحالي وشغّل START-WINDOWS.bat أو npm ci ثم npm run build ثم npm start.
STORE-MANAGER: مجلد مستقل وتوكن مستقل و.env مستقل؛ شغّل START-MANAGER.cmd.

استخدم في المدير MONGO_URI وMONGO_DB_NAME نفسيهما من NSS. جميع سجلات الإدارة والتخصيص والاشتراكات تحفظ في مجموعات store_manager_ تلقائيًا. لا تحتاج Supabase مركزيًا أو SQL لتشغيل المدير.
Supabase وملف SQL مطلوبان لبيانات متجر WWC التابع فقط، كما في النظام الحالي.

إذا لديك متاجر مسجلة بالإصدار القديم في Supabase: أوقف مشغّل start:platform القديم والمدير الجديد، ثم اتبع الاستيراد الاختياري npm run import:legacy في دليل المدير قبل تشغيله. لا يُحذف المصدر ولا يتغير رصيد NSS.
احتفظ بمفتاح تشفير سجل المتاجر القديم للاستيراد، ثم اضغط تحديث ربط الاستضافة لكل متجر قائم في لوحة المدير.
القوالب المرفقة فارغة؛ لا تستبدل بها .env المعبأ مسبقًا.
