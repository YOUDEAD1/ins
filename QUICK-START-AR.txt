LARA STOCK — الحزمة الكاملة

1. فك ضغط الملف كاملًا، ثم ادخل مجلد LARA-STOCK.
2. اضغط EDIT-ENV.cmd لفتح ملف المتغيرات، وعبّئ TOKEN وMONGO_URI وOWNER_ID وOWNER_USER، ثم احفظ وأغلق المحرر.
3. اضغط START-BOT.cmd. سيجهّز بيئة Python منفصلة ويثبّت المكتبات عند الحاجة ثم يبدأ البوت.

إذا لم تعبّئ المتغيرات، سيطلبها منك ملف التشغيل محليًا. إذا لم يكن Python مثبتًا، سيعرض رابط الموقع الرسمي. Python 3.12 هو الإصدار المستخدم في الفحص.

الحزمة تضم البوت كاملًا، الموقع وصوره وإيموجياته، المتغيرات، ملفات المكتبات، التشغيل، وتقارير الاختبار. بياناتك السرية غير مضافة؛ أنت تعبّئها على جهازك.

قبل تشغيل نفس التوكن محليًا، أوقف أي نسخة منه تعمل على Render أو جهاز آخر لتجنب تعارض Telegram.

لم يُشغّل البوت أو يُرفع عند تجهيز هذه الحزمة. لا تتطلب عملية فك الضغط تشغيلًا. التشغيل الفعلي يبدأ عند تشغيل START-BOT.cmd وإدخال بيانات صحيحة.
